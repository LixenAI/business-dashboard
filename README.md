# LixenAI Operations Dashboard

Interactive dashboard consolidating all LixenAI company data — Brand Guide, Company Playbook, Pricing Guide, and Agency HQ Build List.

## Features

- **Overview** — KPI cards, revenue charts, build progress tracker
- **Pricing Hub** — Service plan comparison, partner tiers, retail pricing calculator
- **Build Tracker** — 266 tasks across 10 phases with full Where/Detail instructions
- **Financials** — Operating costs, break-even analysis, profitability calculator
- **CRM Pipeline** — Kanban boards, lead qualification flows, contact fields
- **Brand & Voice** — Color palette, typography, voice rules
- **Market Verticals** — 12 industry verticals with sales guidance
- **Company Playbook** — Partner program, service plans, financial model, voice rules, lead flows

## Tech Stack

- React 19 + TypeScript + Vite
- Tailwind CSS + shadcn/ui
- Framer Motion + Recharts
- Lucide React icons
